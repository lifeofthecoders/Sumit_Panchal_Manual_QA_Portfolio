## Getting Started

### Prerequisites

Install the following before running the project:

- [Node.js](https://nodejs.org/) (use a supported LTS release)
- npm (included with Node.js)
- Git

### 1. Clone the repository

```bash
git clone https://github.com/lifeofthecoders/Sumit-Panchal-QA-Portfolio.git
```

### 2. Navigate to the project directory

```bash
cd Sumit_Panchal_Manual_QA_Portfolio
```

If your cloned repository uses a different folder name, navigate into that folder instead.

### 3. Install dependencies

```bash
npm install
```

### 4. Start the development server

```bash
npm run dev
```

Open [http://localhost:3000](http://localhost:3000) in your browser.

## Deployment

This is a Next.js application. Deploy it to a platform that supports Next.js, such as [Vercel](https://vercel.com/).

General deployment steps:

1. Push the project to a GitHub repository.
2. Import the repository into Vercel.
3. Keep the detected Next.js framework settings.
4. Deploy the project.
5. Add the resulting production URL to the portfolio metadata and social preview configuration.

The repository's `next.config.js` contains custom webpack handling for shader-related file extensions. Review deployment settings if you change the build environment or hosting provider.
